# 极简入门：构建基础问答智能体
## 1. 案例简介
本案例带你快速搭建一个最简单的对话问答Agent，无需复杂配置，体验agentUniverse的基础运行流程，适合新手验证环境是否正常。

## 2. 前置准备
1. 已完成agentUniverse环境部署，依赖安装完成
2. 准备好大模型API Key（以通义千问为例，可替换其他支持的LLM）

## 3. 项目目录结构
simple_agent/
├── agent/
│   └── simple_agent.yaml
└── config.yaml
## 4. 编写Agent配置文件 agent/simple_agent.yaml
```yaml
name: simple_qa_agent
description: 基础问答智能体，回答用户普通问题
profile: 你是一名乐于助人的助手，简洁清晰回答用户提问。
##5. 全局配置 config.yaml
llm:
  default:
    name: qwen_llm
    api_key: "你的API_KEY"
    model_name: qwen-turbo
##6.运行代码 main.py
from agentuniverse.agent import Agent
from agentuniverse.base import AgentUniverse

# 初始化框架
AgentUniverse().start(config_path="config.yaml")

# 加载agent
agent = Agent("simple_qa_agent")

# 执行对话
res = agent.run(input="简单介绍一下agentUniverse是什么？")
print(res)
##7. 执行命令
python main.py
##8. 预期输出
agentUniverse 是一个开源的 AI Agent 开发框架，支持快速搭建、编排智能 Agent，支持自定义组件、工具、知识库等能力。
##9. 常见问题
1. 报错提示 API Key 为空：检查 config.yaml 里面密钥填写，不要带多余空格。
2. 模型调用失败：确认网络可访问模型服务，核对模型名称。
3. 模块找不到：确认 agentUniverse 依赖已经成功安装。
