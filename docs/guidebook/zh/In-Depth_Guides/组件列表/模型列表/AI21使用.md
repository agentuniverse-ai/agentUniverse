# AI21（Jamba）使用

`AI21LLM` 将 [AI21 Labs](https://www.ai21.com) 的 API 接入 agentUniverse。AI21 是 **Jamba** 系列大模型背后的公司，Jamba 基于 SSM-Transformer 混合架构（Mamba + Transformer + MoE）构建，能以远低于纯 Transformer 的显存开销服务超长上下文，当前包括 Jamba 1.5 世代（`jamba-1.5-mini` / `jamba-1.5-large`）与 Jamba 1.6 世代（`jamba-mini-1.6` / `jamba-large-1.6`），上下文窗口均为 256k token。

AI21 提供了完全 **兼容 OpenAI** 的 Chat Completions API（地址为 `https://api.ai21.com/studio/v1`），因此 `AI21LLM` 组件只需继承 `OpenAIStyleLLM`，并在其基础上配置 AI21 的鉴权信息、API 基础地址以及各模型的上下文长度表即可。流式输出、工具调用、异步接口以及 LangChain 桥接等能力均可直接复用，无需额外开发。

---

## 1. 创建相关文件

创建一个 yaml 文件，例如 `user_ai21_llm.yaml`，将以下内容粘贴进去：

```yaml
name: 'user_ai21_llm'
description: 'user ai21 llm powered by the AI21 Labs Jamba models'
model_name: 'jamba-1.5-mini'
max_tokens: 1000
temperature: 0.5
streaming: True
api_key: '${AI21_API_KEY}'
api_base: 'https://api.ai21.com/studio/v1'
proxy: '${AI21_PROXY}'
metadata:
  type: 'LLM'
  module: 'agentuniverse.llm.default.ai21_llm'
  class: 'AI21LLM'
```

源码目录中同时附带了一个开箱即用的模板 `agentuniverse/llm/default/ai21_llm.yaml.example`。

**note:** `api_key` / `api_base` / `proxy` 等模型参数有三种配置方法：

1. **直接字符串值**：直接在配置文件中输入 API 密钥字符串。

    ```yaml
    api_key: 'ai21-***'
    ```

2. **环境变量占位符**：使用 `${VARIABLE_NAME}` 语法从环境变量中加载。当 agentUniverse 启动时，会自动从环境变量读取相应的值。

    ```yaml
    api_key: '${AI21_API_KEY}'
    ```

3. **自定义函数加载**：使用 `@FUNC` 注解在运行时通过自定义函数动态加载 API 密钥。

    ```yaml
    api_key: '@FUNC(load_api_key(model_name="ai21"))'
    ```

    该函数需要在 `yaml_func_extension.py` 文件的 `YamlFuncExtension` 类中定义，可参考样例工程中的 [YamlFuncExtension](../../../../../../examples/sample_standard_app/config/yaml_func_extension.py)。当 agentUniverse 加载此配置时：
    - 解析 `@FUNC` 注解
    - 执行 `load_api_key` 函数并传入相应参数
    - 用函数返回值替换注解内容

## 2. 选择模型

AI21 会持续发布新的 Jamba 模型。下表列出了 AI21 API 当前提供的模型及其上下文窗口大小（输入 + 输出 token）。这些数值同样硬编码在 `AI21LLM.max_context_length` 中，这样 agentUniverse 即使不发起真实请求也能正确估算 prompt 预算。

| 模型名称          | 上下文长度        |
| ----------------- | ----------------- |
| `jamba-1.5-mini`  | 256000 (256k)     |
| `jamba-1.5-large` | 256000 (256k)     |
| `jamba-mini-1.6`  | 256000 (256k)     |
| `jamba-large-1.6` | 256000 (256k)     |

AI21 会为每个模型同时发布带日期的快照版本（例如 `jamba-mini-1.6-20250310`）。`AI21LLM` 会自动去掉结尾的 `-YYYYMMDD` 日期后缀，将快照版本解析为基础模型的上下文窗口。

请以 [AI21 官方文档](https://docs.ai21.com) 公布的最新列表为准。如果某个模型不在上表中，`AI21LLM` 会保守地回退到 8192 token。

## 3. 环境设置

示例 yaml 中模型密钥等参数使用了环境变量占位符，下面介绍环境变量的设置方法。

必须配置：`AI21_API_KEY`
可选配置：`AI21_API_BASE`、`AI21_PROXY`

### 3.1 通过 Python 代码配置

```python
import os
os.environ['AI21_API_KEY'] = 'ai21-***'
os.environ['AI21_API_BASE'] = 'https://api.ai21.com/studio/v1'
```

### 3.2 通过配置文件配置

在项目的 `config` 目录下的 `custom_key.toml` 当中，添加配置：

```toml
AI21_API_KEY="ai21-******"
AI21_API_BASE="https://api.ai21.com/studio/v1"
AI21_PROXY=""
```

## 4. AI21 API KEY 获取

1. 登录 [https://platform.ai21.com](https://platform.ai21.com)。
2. 进入 **API Keys** 页面并创建新的密钥。
3. 复制生成的密钥，并赋值给 `AI21_API_KEY`。

计费、速率限制与免费额度说明详见 [AI21 官方文档](https://docs.ai21.com)。

## 5. 在代码中使用

配置被 agentUniverse 加载后，您可以直接获取 LLM 实例并调用：

```python
from agentuniverse.llm.default.ai21_llm import AI21LLM

llm = AI21LLM(model_name='jamba-1.5-mini')

# 非流式
output = llm.call(messages=[{"role": "user", "content": "你好！"}])
print(output.text)

# 流式
for chunk in llm.call(messages=[{"role": "user", "content": "从 1 数到 5。"}], streaming=True):
    print(chunk.text, end='')

# 异步
import asyncio
async def main():
    out = await llm.acall(messages=[{"role": "user", "content": "你好！"}])
    print(out.text)
asyncio.run(main())
```

由于 AI21 兼容 OpenAI 协议，`OpenAIStyleLLM` 支持的所有能力（工具调用、LangChain 集成、链路追踪等）都可以直接使用。

---

## 6. Tips

- agentuniverse 源码中内置了一个 name 为 `default_ai21_llm` 的模板配置（`ai21_llm.yaml.example`），用户将其重命名为 `ai21_llm.yaml` 并配置 `AI21_API_KEY` 之后即可直接使用。
- `jamba-mini-1.6` / `jamba-1.5-mini` 是速度快、价格低的版本，而 `jamba-large-1.6` / `jamba-1.5-large` 是面向复杂推理与生成任务的旗舰版本。
- Jamba 全系模型均提供 256k token 的上下文窗口，非常适合需要将大量检索文档一次性填入 prompt 的 agentUniverse 知识库型智能体。
