# 离线组件配置预检

启动服务前运行：

```sh
python -m agentuniverse.base.config.preflight agent.yaml knowledge.yaml
```

输出 JSON 图包含组件类型、名称、引用边以及文件和字段定位。退出码 0 表示声明范围内检查通过，1 表示错误，2 表示尚有未解析项。不会导入配置类、实例化组件、求值 @FUNC、读取环境变量或启动服务。

Python API `inspect_components` 接受显式文件列表。`class_types` 声明 meta_class 的类型；`external` 声明未选中文件中的外部组件，格式为 `STORE:sqlite`。`capabilities` 和 `requirements` 用组件 ID 映射能力字符串列表，检查声明是否满足要求。这些声明不是运行时可用性的证明。

内置规则覆盖 Agent 的 LLM、Prompt、Planner、Memory、Tool、Toolkit、Knowledge 引用和 Knowledge 的 Store、Reader、处理器、路由、改写器引用。可以使用 `reference_fields={"TOOL": {"delegate": "TOOL"}}` 添加自定义声明；星号选择列表元素或映射值。未提供规则的类型标记为覆盖不完整。循环只表示声明的引用成环，不等同于运行时死锁。

Agent 身份使用 info.name；Prompt 使用 metadata.version 或运行时路径回退；其他组件使用 name。同类型重名报告错误，不猜测加载顺序。meta_class 类型必须显式声明，否则标记未解析；动态字符串也不求值。不会推断默认 LLM/Router、TOML 引导、SQL 覆盖层或任意 Python 继承行为。

文件数、字节数、嵌套层数和展开节点数有界；重复键、非字符串键、YAML 合并键被拒绝。报告不包含配置值或原始解析异常片段，但包含组件名称和路径，分享前应检查。原文件不变。完整 API 示例和范围见英文 Offline_Component_Preflight.md。
