# 语料版本影响报告

`corpus_impact.compare_corpora` 先验证两个完整来源清单的文本摘要，再报告新增、删除、原文变化、位置变化、分块变化和旧引用受影响原因。只读，不依赖语料包导入功能，不修改 Store。

```python
from agentuniverse.agent.action.knowledge.corpus_impact import source_record, compare_corpora
old = {"version": 1, "sources": [source_record("manual", "第一行\n旧内容\n")]}
new = {"version": 1, "sources": [source_record("manual", "第一行\n新内容\n")]}
report = compare_corpora(old, new, [{"id": "citation-1", "source_id": "manual", "start_line": 2, "end_line": 2}])
```

`source_record` 接受稳定来源 ID、显式正文、位置标签和可选 `{id, text}` 分块列表；真实 Document 可提供 doc.id/doc.text。清单 V1 的完整字段和英文格式说明见 Corpus_Version_Impact.md。原文和分块摘要均基于未经换行/Unicode归一化的 UTF-8 字节。重复 ID、错误摘要、未知字段或版本均拒绝。

原文不变而分块边界变化，不会误报原文改变。来源 ID 决定身份；同 ID 改路径只报告位置变化。删除/新增来源的内容摘要相同只列为可能匹配，不自动认定重命名。来源与分块关联由调用者声明，不证明推导关系。

引用的 start_line/end_line 是旧来源的一基闭区间，报告的行差异是零基半开区间。未知旧来源或分块标记 unresolved；改变或删除的目标标记 affected。源内容改变时，即使引用锚点原样保留，也需要检查语境。重复行可能有多种对齐方式，确定性文本对齐不是权威来源证明。

CLI：`python -m agentuniverse.agent.action.knowledge.corpus_impact old.json new.json --references references.json`。文件大小、来源/分块/引用数、正文总字节与行比较工作量有界；超过行比较预算明确报告不可用，仍保留摘要变化判断。输入文件不变，报告不输出原文。内部摘要不认证作者，不做自动修复、语义真实性判定或 Store 同步。
